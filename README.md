💪 Health Tracker

A simple and efficient Python-based Health Tracker application that helps users calculate BMI, store health records, analyze health status, and receive basic health recommendations.

Features

- Add Health Records
- Calculate BMI (Body Mass Index)
- View All Saved Records
- Search Records by Name
- Health Status Analysis
- Personalized Health Tips
- CSV File Storage
- User-Friendly Command Line Interface

🛠️ Technologies Used

- Python 3
- CSV Module
- OS Module
- Datetime Module

📊 BMI Categories

BMI Range| Status
Below 18.5| Underweight
18.5 - 24.9| Normal Weight
25 - 29.9| Overweight
30 and Above| Obese

How to Run

1. Clone the repository

git clone https://github.com/your-username/Health-Tracker.git

2. Navigate to the project folder

cd Health-Tracker

3. Run the application

python health_tracker.py
